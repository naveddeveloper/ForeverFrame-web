# ForeverFrame 💍

### An Interactive Digital Wedding Experience

ForeverFrame is a premium digital wedding invitation built with **C++, WebAssembly, WebGL, JavaScript, HTML, and CSS**.

The project combines cinematic visuals, smooth scroll-driven animations, interactive storytelling, photography, video, music, wedding timelines, FAQ interactions, and RSVP into one immersive web experience.

## ✨ Features

- 🎬 Cinematic intro video
- 🎵 Custom wedding music
- 📜 Scroll-driven animations
- 💍 Interactive wedding invitation
- 📖 Couple story timeline
- 📅 Wedding day schedule
- 🖼️ Interactive photography
- ❓ Animated FAQ
- 💌 RSVP experience
- 📱 Responsive design

## 🛠️ Built With

- **C++** — Core animation and rendering logic
- **WebGL** — Interactive GPU-powered visuals
- **WebAssembly** — Runs C++ in the browser
- **Emscripten** — Compiles C++ to WebAssembly
- **JavaScript** — Browser events and WebAssembly communication
- **HTML5** — Structure and media
- **CSS3** — Layout, typography and styling

## 🏗️ Architecture

```text
C++
 ↓
Emscripten
 ↓
WebAssembly
 ↓
WebGL
 ↓
Browser

JavaScript connects browser interactions such as scrolling, mouse movement, audio, video, and buttons with the C++/WebAssembly rendering engine.
```
## 💼 Client Benefits

ForeverFrame transforms a traditional wedding invitation into a memorable digital experience.

Clients can provide their own:

- 📸 Photos
- 🎬 Videos
- 🎵 Music
- 💕 Wedding story
- 📅 Event details
- 📍 Venue information
- 💌 RSVP information

Everything is presented in one premium, shareable website that can be sent through **WhatsApp, Instagram, Email, QR codes, or social media**.

Instead of simply sending an invitation, clients can give their guests an **interactive experience that tells their story**.

## 🎯 Project Goal

> **Turn a wedding invitation into a memory before the wedding even begins.**

ForeverFrame combines **creative design + C++ + WebGL + WebAssembly + modern web technologies** to create an immersive wedding experience.
